# 语法分析器与语义翻译器

## 项目简介
本项目在词法分析器（lexer）的基础上，构建了一个LR(1)语法分析器，并集成了语义翻译功能。它能够将C语言子集源代码翻译为四元式（中间代码），同时构建符号表。

## 功能特性
### 词法分析
- 与词法分析器（lexer）相同的词法分析功能

### 语法分析
- **LR(1)分析算法**：自动构建LR(1)分析表，支持规范的移进-归约分析
- **增广文法**：自动添加 `PROG' -> PROG` 作为起始产生式
- **FIRST集计算**：迭代计算所有非终结符的FIRST集
- **项目集族构建**：生成规范LR(1)项目集族
- **分析表生成**：自动生成ACTION和GOTO表

### 语义翻译
- **符号表管理**：记录变量名、类型、偏移量
- **临时变量生成**：自动生成带类型后缀的临时变量（如 `T0_i`, `T1_d`）
- **四元式生成**：输出标准的四元式中间代码
- **回填技术**：实现条件跳转和循环控制流的回填

### 支持的语法结构
- 变量声明：`int a, b;` / `double x, y;`
- 赋值语句：`a = b + c;`
- 输入语句：`scanf(a, b);`
- 输出语句：`printf(a, b);`
- 条件语句：`if B then S`
- 循环语句：`while B do S`
- 复合语句：`{ S; S; }`
- 算术表达式：`+`, `-`, `*`, `/`, `!`
- 逻辑表达式：`&&`, `||`
- 关系表达式：`==`, `!=`, `<`, `<=`, `>`, `>=`

## 编译与运行

### 编译
```bash
g++ main.cpp -o parser
# 或直接运行 build.sh
./build.sh
```

### 运行
```bash
./parser < input.txt
```

### 输入格式
输入为C语言子集源代码，通过标准输入读取。

### 输出格式
1. **符号表大小**：第一行输出符号表条目数
2. **符号表条目**：每行格式 `名称 类型(0=int,1=double) 值 offset`
3. **临时变量个数**：输出的临时变量总数
4. **四元式数量**
5. **四元式列表**：每行格式 `序号: (操作符, arg1, arg2, result)`

#### 四元式操作符说明
| 操作符 | 说明 |
|--------|------|
| `=` | 赋值 |
| `+`, `-`, `*`, `/` | 算术运算 |
| `&&`, `\|\|`, `!` | 逻辑运算 |
| `==`, `!=`, `<`, `<=`, `>`, `>=` | 关系运算 |
| `j` | 无条件跳转 |
| `jnz` | 非零跳转 |
| `j==`, `j!=`, `j<`, `j<=`, `j>`, `j>=` | 条件跳转 |
| `R` | 读操作（scanf） |
| `W` | 写操作（printf） |
| `End` | 程序结束 |

## 技术要点
### LR(1)分析表构建
1. 定义文法产生式及语义动作
2. 计算所有符号的FIRST集
3. 构建规范LR(1)项目集族
4. 生成ACTION（移进/归约/接受）和GOTO表

### 语义动作实现
- 每个产生式关联一个lambda函数
- 在规约时执行语义动作，完成：
  - 符号表插入
  - 四元式生成
  - 回填链表的合并与回填

### 回填技术
- `truelist` 和 `falselist` 存储待回填的四元式序号
- `N` 产生式记录当前四元式序号，用于回填跳转目标
- `backpatch()` 函数将指定列表中的所有四元式回填为目标地址

## 错误处理
- 词法错误：输出错误信息并退出
- 语法错误：输出 `Syntax Error` 并退出
- 语义错误（未定义变量等）：输出 `Syntax Error` 并退出
