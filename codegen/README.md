# 目标代码生成器

## 项目简介
本项目将语法分析器（parser）生成的中间代码（四元式）翻译为x86汇编风格的目标代码。采用寄存器分配算法（待用-活跃信息分析），优化寄存器使用效率。

## 功能特性
### 寄存器分配
- **待用-活跃信息分析**：每个变量在基本块内的下一次引用点（use）和出口活跃状态（live）
- **寄存器分配策略**：
  1. 若变量已独占寄存器且满足复用条件，直接使用
  2. 若有空闲寄存器，直接分配
  3. 否则选择最远下次使用的寄存器进行溢出
- **寄存器描述符**：记录每个寄存器中存放的变量集合
- **地址描述符**：记录每个变量的值当前所在位置（寄存器/内存）

### 目标代码生成
- **指令映射**：
  - 算术运算 → `add`, `sub`, `mul`, `div`
  - 逻辑运算 → `and`, `or`, `not`
  - 关系运算 → `cmp` + `sete`/`setne`/`setl`/...
  - 跳转指令 → `jmp`, `je`, `jne`, `jl`, `jle`, `jg`, `jge`
- **内存访问**：使用 `[ebp-offset]` 格式访问栈帧
- **输入输出**：`scanf` 和 `printf` 映射为 `jmp ?read` 和 `jmp ?write`

### 基本块划分
- 识别基本块入口：跳转目标、跳转指令后的第一条指令
- 控制流指令（`j`, `jnz`, `j==`, `j!=` 等）作为基本块结束标志
- 为每个基本块独立进行寄存器分配

### 标签管理
- 为跳转目标四元式生成标签（如 `?5:`）
- 确保控制流正确跳转

## 编译与运行

### 编译
```bash
g++ main.cpp -o codegen
# 或直接运行 build.sh
./build.sh
```

### 运行
```bash
./codegen < quads.txt
```

### 输入格式
输入为语法分析器（parser）输出的四元式格式，通过标准输入读取，包括：
1. 符号表
2. 临时变量个数
3. 四元式数量
4. 四元式列表

输入示例：
```
3
a 0 null 0
b 0 null 4
c 0 null 8
2
10
0: (=, 5, -, T0_i)
1: (=, T0_i, -, a)
...
```

### 输出格式
输出为x86风格汇编代码，包括：
- 标签定义（如 `?5:`）
- 数据传送指令（`mov`）
- 算术/逻辑指令（`add`, `sub`, `mul`, `div`, `and`, `or`, `not`）
- 比较与条件设置指令（`cmp`, `sete`, `setne`, ...）
- 跳转指令（`jmp`, `je`, `jne`, ...）
- 输入输出调用（`jmp ?read`, `jmp ?write`）
- 程序结束（`halt`）

输出示例：
```
?0:
mov R0, 5
mov [ebp-12], R0
?2:
mov R1, [ebp-12]
add R1, 3
mov [ebp-12], R1
halt
```

## 寄存器分配算法详解

### 待用-活跃信息计算
1. 对每个基本块，从后向前扫描四元式
2. 初始状态：非临时变量出口活跃，临时变量出口不活跃
3. 遇到 `z`（左值）：记录当前待用信息后置为不活跃
4. 遇到 `x` 或 `y`（右值）：记录当前待用信息后更新为当前四元式

### getReg 函数策略
1. **复用条件**：x独占寄存器，且x与z相同或x不再使用
2. **空闲分配**：直接使用空闲寄存器
3. **溢出选择**：
   - 优先选择所有值都在内存中的寄存器
   - 否则选择最远下一次使用的寄存器
4. **溢出操作**：将寄存器的值存回内存，更新地址描述符

### 变量类型
- **临时变量**：以 `T` 开头，不跨基本块活跃，可被溢出
- **用户变量**：以 `TB` 开头，出口活跃，需要存回内存

## 指令集参考
| 指令 | 说明 |
|------|------|
| `mov dest, src` | 数据传送 |
| `add dest, src` | 加法 |
| `sub dest, src` | 减法 |
| `mul dest, src` | 乘法 |
| `div dest, src` | 除法 |
| `and dest, src` | 按位与 |
| `or dest, src` | 按位或 |
| `not dest` | 按位取反 |
| `cmp a, b` | 比较 |
| `sete dest` | 相等置1 |
| `setne dest` | 不等置1 |
| `setl dest` | 小于置1 |
| `setle dest` | 小于等于置1 |
| `setg dest` | 大于置1 |
| `setge dest` | 大于等于置1 |
| `jmp label` | 无条件跳转 |
| `je label` | 相等跳转 |
| `jne label` | 不等跳转 |
| `jl label` | 小于跳转 |
| `jle label` | 小于等于跳转 |
| `jg label` | 大于跳转 |
| `jge label` | 大于等于跳转 |
| `halt` | 停机 |
